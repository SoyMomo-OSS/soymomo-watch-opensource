# Security

To report a security vulnerability in a SoyMomo device, app or service, email
**opensource@soymomo.com** with "Security" in the subject. Please don't report
vulnerabilities in public issues.

## Español

Para reportar una vulnerabilidad de seguridad en un dispositivo, app o servicio
de SoyMomo, escribe a **opensource@soymomo.com** con "Seguridad" en el asunto.
Por favor, no reportes vulnerabilidades en issues públicos.
